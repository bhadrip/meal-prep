# UI and backend test coverage

The full interaction suite runs in desktop Chromium, Android Chrome (Pixel 7), and iPhone WebKit (iPhone 13) emulation. Each browser profile uses a separate demo server so saved state cannot contaminate another profile. Tests use the rendered website or MCP App and check resulting state, including rejected writes, corrected retries, and reloads. The backend suite checks the corresponding HTTP/MCP routes; local Supabase integration tests check authenticated database paths.

`pnpm test:ui` runs all three profiles. Use `pnpm test:ui --project=android --project=iphone` for phones, or `pnpm test:ui ui-tests/mobile.spec.js` for the dedicated layout/touch checks. Install both engines with `pnpm exec playwright install --with-deps chromium webkit`. CI runs the same three profiles and retains traces/screenshots on failure. Tests simulate reduced viewport height for keyboard exposure; physical device keyboards, browser chrome and hardware still need a real-device check.
