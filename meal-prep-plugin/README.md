# Meal Prep

Meal Prep combines a reusable planning skill with a remote MCP connector. ChatGPT loads household context, dietary restrictions, preferred stores, weekly schedules, retrospectives, household memories, saved recipes, and pantry data before proposing a plan. The remote service persists approved meal plans and shopping lists in Supabase and can render an interactive weekly calendar or store-grouped checklist. Saving a list never places an order.

After installing the plugin, open its **Connectors** tab and connect the Meal Prep service. Authentication is handled by the service's OAuth flow.
