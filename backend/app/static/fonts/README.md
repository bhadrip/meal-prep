Self-hosted Latin-subset WOFF2 files from Google Fonts, used by the website so
its typography does not depend on a runtime font CDN:

- Bricolage Grotesque variable: Google Fonts `bricolagegrotesque/v9`
- IBM Plex Sans variable: Google Fonts `ibmplexsans/v23`
- IBM Plex Mono 500: Google Fonts `ibmplexmono/v20`

The corresponding SIL Open Font License text is preserved beside each font.
Characters outside each Latin subset fall back to the system font stack.
